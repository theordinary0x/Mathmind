# MathMind

基于 Web 的数学公理推导与命题图谱工具，用于梳理概念逻辑依赖与推导脉络。

## 快速运行 (免克隆源码)

只要电脑安装了 Node.js (>= 18)，在终端直接运行：

```bash
npx mathmind
```
命令会自动启动本地轻量服务并唤起默认浏览器。

亦可全局安装为系统命令行工具：
```bash
npm install -g mathmind
mathmind
```

## 源码开发与构建

如需本地二开或调试：

```bash
# 安装项目依赖
npm install

# 启动本地 Vite 开发服务器
npm run dev

# 生产环境打包构建
npm run build
```

## 主要功能

- **命题分类与连线**：支持公理、定义、命题、定理、推论 5 种节点类型，支持画布拖拽交互与面板勾选建立前置依赖连线。
- **数学公式排版**：基于 KaTeX 引擎，支持行内 `$ ... $` 与独立 `$$ ... $$` 公式，编辑模式下支持各字段实时渲染预览与标题多行折行。
- **图谱布局算法**：内置分层拓扑因果流（Dagre）与力导向聚类（CoSE）两种布局，支持平滑聚焦动画。
- **视觉主题与材质**：支持明暗双色主题，提供经典白底、深灰、羊皮纸与黑板材质风格。
- **本地数据管理**：数据完全存储在浏览器本地 localStorage 中，支持一键导出与导入 JSON 体系文件。

## 常用快捷键

| 快捷键 | 功能 |
| :--- | :--- |
| `Ctrl + N` / `N` | 新建命题 |
| `Ctrl + Enter` | 保存命题修改 / 提交新建 |
| `Ctrl + S` | 保存项目数据到本地存储 |
| `L` | 开启 / 退出连线模式 |
| `1` / `2` | 切换布局（1: 分层拓扑 Dagre，2: 力导向 CoSE） |
| `0` | 画布全览居中 (适应视口) |
| `+` / `-` | 放大 / 缩小画布 |
| `T` | 切换明暗主题 |
| `Ctrl + P` | 打开项目管理面板 |
| `Ctrl + ,` | 打开系统设置 |
| `?` | 查看完整快捷键对照表 |
