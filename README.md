# MathMind

MathMind 是一个基于 Web 的数学知识图谱与命题逻辑推演工作台。

传统的线性文档和大纲笔记难以准确表达数学命题之间的网状脉络。MathMind 将数学体系建模为**有向无环拓扑图（DAG）**，以公理与基石定义为起点，直观呈现定理证明与后续推论的逻辑脉络，帮助学习者与研究者理清因果依赖关系、追踪证明推导、构建全局认知。

---

## 快速启动

### 1. 免克隆免配置直接运行 (推荐)
只要本地安装了 Node.js (>= 18)，在终端执行以下命令即可自动启动轻量本地服务器并唤起默认浏览器：

```bash
npx mathmind
```

也可以全局安装为系统命令：
```bash
npm install -g mathmind
mathmind
```

### 2. 源码调试与本地开发
如需进行二次开发或本地构建：

```bash
# 克隆仓库
git clone https://github.com/theordinary0x/Mathmind.git
cd Mathmind

# 安装依赖
npm install

# 启动本地 Vite 开发服务器
npm run dev

# 生产环境打包构建 (严格分包，零超标警告)
npm run build
```

## 核心特性

### 1. 严格的拓扑推演与知识图谱画布
- **5 类数学实体**：内置公理 (Axiom)、定义 (Definition)、命题 (Proposition)、定理 (Theorem)、推论 (Corollary) 规范分类。
- **因果依赖连线**：支持画布拖拽快速连线、单键连线模式（`L`）以及属性面板精准勾选前置依赖。
- **两种工业级布局算法**：
  - **Dagre 分层布局**：按逻辑层级自动排列，直观展现由前提向结论的因果推演流；
  - **CoSE 力导向布局**：基于物理弹性力学模型自动聚类，展示紧密相关的定理群落。
- **高效批量操作**：提供矩形框选（Box Selection，按 `B` 或 `Shift+拖拽`）与自由套索圈选（Lasso Selection，按 `Alt+拖拽`），支持多节点批量移动与批量安全删除。

### 2. 实例与算例系统 (Multi-Example Support)
- 每个命题支持挂载 0 到多个**典型实例、计算示范或反例**。
- **阅读视图**：以结构化编号卡片展示实例，支持独立 KaTeX 高精度数学公式排版。
- **编辑视图**：支持动态添加、删除与公式实时渲染预览，并与数学符号快捷输入工具栏无缝联动。

### 3. 多模态 AI 教材智能录入与 Copilot 助手
- **多模态教材提取**：支持粘贴教材纯文本、剪贴板公式截图（`Ctrl+V`）或上传 PDF 讲义与论文。AI 自动解析提取其中的核心定理、公式陈述与证明，并智能匹配画布中已有节点建立拓扑依赖。
- **多会话数学 Copilot**：内置常驻智能助手，能够感知当前图谱上下文，协助补全分步严密推导（Full Proof）、检查前提完备性、提出启发式变式。
- **主流大模型兼容**：支持配置 Google Gemini、DeepSeek、阿里通义千问 (Qwen) 以及智谱 (GLM) 的 API Key 与 Base URL，请求直连官方接口，无中间代理。

### 4. 研读进度与逻辑状态标记
- 为命题提供 4 种标准研读标记：
  - **存疑 (Doubt)**：标记理解不充分或证明存在盲点的命题；
  - **重点 (Core)**：核心主定理或考试重点；
  - **需复习 (Review)**：用于定期回顾与逻辑复盘；
  - **已证毕 (Verified)**：推导已完全消化与验证。
- 支持按状态在画布中高亮检索与图例筛选。

### 5. 纯直角工程美学与公式渲染
- 全局采用纯直角几何与正交折线设计，杜绝冗余视觉干扰。
- 搭载 KaTeX 实时排版引擎，全面支持行内公式 (`$...$`) 与行间独立展示公式 (`$$...$$`)。
- 内置 4 种背景材质风格：白底网格 (Paper)、极简深灰 (Dark)、古典羊皮纸 (Parchment)、教学黑板 (Chalkboard)。

### 6. 全键盘交互系统
全功能覆盖键盘映射，在浏览和编辑模式间无缝切换，且内置输入法合成保护（打字时不触发快捷键）：

| 快捷键 | 功能描述 |
| :--- | :--- |
| `N` / `Ctrl + N` | 新建命题 |
| `E` | 在选中的命题详情中切换 阅读 / 编辑 模式 |
| `Ctrl + Enter` | 保存命题编辑 / 提交新建 / 确认修改 |
| `Esc` | 取消编辑 / 关闭当前弹窗 / 退出连线模式 |
| `L` | 开启 / 退出依赖连线模式 |
| `B` / `Shift + 拖拽` | 矩形框选模式 |
| `Alt + 拖拽` | 自由套索圈选模式 |
| `1` / `2` | 快速切换布局（1: 分层 Dagre，2: 力导向 CoSE） |
| `0` / 空格双击 | 画布全览居中 (适应视口) |
| `+` / `-` | 放大 / 缩小画布 |
| `T` | 快速切换明暗外观主题 |
| `Ctrl + P` | 打开数学公理体系与项目管理 |
| `Ctrl + ,` | 打开系统设置与 API 配置 |
| `Shift + I` | 唤起 AI 多模态教材录入 |
| `?` | 打开完整键盘快捷键对照表 |

### 7. 本地隐私与体系管理
- **零服务端依赖**：所有图谱数据、API 配置与历史记录均保存在浏览器本地，完全离线可用，不上传任何用户数据。
- **多体系隔离**：支持并行维护多个独立的数学分支体系（如《皮亚诺算术》、《线性代数》、《实分析》等）。
- **导入与导出**：支持标准 JSON 结构化体系数据的导入与备份，支持将推导图谱无损导出为高清 PNG 图像。

## 技术架构

- **UI 框架**：React 18 + TypeScript + Vite 6
- **图计算与渲染引擎**：Cytoscape.js、cytoscape-dagre、cytoscape-cose-bilkent
- **数学排版**：KaTeX、Marked
- **样式方案**：Tailwind CSS
- **构建优化**：Rollup manualChunks 精准分包（按 React 核心、图引擎、布局算法、数学库解耦，单包小于 450 kB）
